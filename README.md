An original dependency-free ES module CSV reader: a faster drop-in for
csv-reader 1.0.0 that answers exactly as it does on every case, including
its broken-row policy (stray CRs, quotes that never close, junk after a
closing quote, short and long rows). Import `run` from `solve.js`, or run
`node main.ts` to answer the harness input. Local runs accept
`MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR`.
